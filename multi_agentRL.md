### Contribution
 - They proposed an highly scalable **Many Agent** platform that can able to host millions of agent in a GPU server.
 - MAgent provides environment, agent configurations and a reward description language to enable flexible environment design.
 - Illustrate three running example of **Many Agent** simulation of pursuitting, Gathering and Battle field agents.
 - Implemented three parameter sharing DQN, DRQN, A2C and found DQN perform best in their setting.

 ### Limitations
 - Not enough technical details about the environment, agent communications, reward design, states, actions.
 - Not provided architectural details of the platform.
